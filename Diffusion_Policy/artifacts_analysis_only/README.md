# Analysis-Only Artifacts

This directory stores smoke-test outputs and intermediate analysis products that
supported research decisions but should not be read as final benchmark evidence.

## Groups

| Path pattern | Meaning |
| --- | --- |
| `wm_probe_*` | World-model probe runs for v3/v3.5 diagnostics |
| `phrew*` | Predictive-hardness scoring and reweighting artifacts |
| `dlos_smoke*` | DLOS-DP smoke-test runs |
| `phrew_runs/` | PHRew comparison runs |

Use these files to understand why a direction was stopped. For final conclusions,
read [`../Paper/00_项目收束总结.md`](../Paper/00_项目收束总结.md).
