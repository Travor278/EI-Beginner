# Diffusion Policy v3.6
# 三方向新颖性审查与失败分析

> 目的：在 `v2 / v3.1 / v3.5` 已有实验结果基础上，系统审查三个新方向的
> 1. 新颖性与对应竞品
> 2. 工程可行性
> 3. 与当前 baseline 比较时的胜率
> 4. 我们当前失败的根因

---

## 0. 结论先行

三条候选方向如下：

1. **Action-Relevant Residual World Model**
2. **Privileged-State-Aligned DLOS**
3. **Object-Motion DLOS**

当前排序建议：

| 排名 | 方向 | 新颖性 | 可行性 | 相对容易超过 baseline | 总评 |
| --- | --- | --- | --- | --- | --- |
| 1 | `Action-Relevant Residual World Model` | 中等 | 高 | 中高 | **最平衡，最适合作为主线** |
| 2 | `Privileged-State-Aligned DLOS` | 中等偏低到中等 | 高 | **高** | **最容易先打出正结果** |
| 3 | `Object-Motion DLOS` | 中等偏高 | 中等偏低 | 中等 | **最有研究味，但风险最大** |

一句话判断：

- 如果目标是**最稳地把研究继续推进**，选 `Action-Relevant Residual World Model`
- 如果目标是**尽快在仿真中超过现有 baseline**，选 `Privileged-State-Aligned DLOS`
- 如果目标是**更强的研究故事和更贴操控本质的世界模型交叉**，选 `Object-Motion DLOS`

## 1. 我们已经得到的真实实验事实

### 1.1 v2：手工 curriculum 失败

| 方法 | seed | 最佳 `test/mean_score` |
| --- | ---: | ---: |
| `random` | 42 | `0.862` |
| `random` | 43 | `0.731` |
| `easy_to_hard` | 42 | `0.698` |
| `easy_to_hard` | 43 | `0.701` |
| `hard_to_easy` | 42 | `0.691` |
| `hard_to_easy` | 43 | `0.215` |

结论：

- `sample order` 本身不是问题的核心
- 手工定义的 `difficulty = length + action variance` 没有抓住真正的操控难度

### 1.2 v3.1：predictive-hardness reweighting 失败

| 方法 | seed | 最佳 `test/mean_score` |
| --- | ---: | ---: |
| `uniform` | 42 | `0.9047` |
| `uniform` | 43 | `0.9607` |
| `soft_hard` | 42 | `0.7498` |
| `soft_hard` | 43 | `0.8865` |

结论：

- world-model 信号接入训练是可行的
- 但只把该信号用作 `chunk-level weighting` 不够
- `soft_hard` 反而破坏了训练分布

### 1.3 v3.5：Stage 0 full probe 未过 gate

`OutcomeWorldModel` 当前版本：

- 输入：`DINO(obs_t) + action_t`
- 目标：`DINO(obs_{t+1})`

实测：

| 指标 | 数值 |
| --- | ---: |
| `baseline_mse`（直接 copy `z_t` 作为 `z_{t+1}`） | `0.0931` |
| `best_val_mse`（OutcomeWorldModel） | `0.2020` |

结论：

- 当前 world model **没有超过 trivial copy baseline**
- 按我们自己给 `v3.5` 设的 gate，**不该直接进入 `A/B/C/D/E` full first-pass**

## 2. 我们当前失败的根因分析

### 2.1 失败不是“世界模型完全没用”

从 `v2 -> v3.1 -> v3.5 Stage 0` 的链条看，失败并不是因为 world model 这个方向天然不成立，而更像是：

- 信号接入位置不对
- 表示空间不对
- 训练目标不对

### 2.2 `v2` 失败说明：手工难度与操控本质错位

`length` 和 `action variance` 更像轨迹表面统计量，而不是：

- 接触难度
- 相对位姿难度
- 误差恢复难度
- 目标物体运动难度

所以 `v2` 的负结果更应理解为：

> “手工 difficulty 不够好”，而不是 “curriculum 对 DP 无效”。

### 2.3 `v3.1` 失败说明：把预测信号只放在数据层太弱

`soft_hard` 双 seed 均弱于 `uniform`，说明：

- predictive hardness 的确提供了某种信息
- 但它只改变了**样本权重**
- 没有改变模型内部的表示或约束

更关键的是，`soft_hard` 往 hardest chunks 偏得太激进，会带来：

- 数据分布被扭曲
- rollout 稳定性下降
- 监督 loss 更低但控制效果更差

这表明：

> world-model 信号如果有价值，更应该进入“表示层”或“loss 层”，而不是只停在 sample weighting。

### 2.4 `v3.5 Stage 0` 失败说明：当前 latent 对动作不敏感

当前 `DINO(obs_t) + action -> DINO(obs_{t+1})` 失败，最关键的解释不是模型太小，而是：

1. **预测目标太绝对**
   - Push-T 相邻帧变化很小
   - `z_{t+1} ≈ z_t`
   - 所以 copy baseline 天然很强

2. **表示太全局**
   - frozen DINO CLS 更偏语义和全局稳定性
   - 对单步动作引起的局部几何变化不够敏感

3. **缺少 task-relevant state**
   - 当前 world model 没显式利用：
     - `agent_pos`
     - 物体相对位姿
     - 接触几何

4. **数据支持集太窄**
   - 当前只用 imitation 数据
   - 没有随机探索 rollouts
   - action-conditioned dynamics 更难学

### 2.5 总结成一句话

> 我们当前最缺的，不是更大的 world model，而是一个**对动作敏感、对局部几何敏感、对小步状态变化敏感**的可控表示空间。

## 3. 方向一：Action-Relevant Residual World Model

### 3.1 核心想法

把 world model 从“预测绝对下一步 latent”改成：

- 预测残差：`Δz = z_{t+1} - z_t`
- 同时加入 inverse dynamics 头：
  - 输入：`(z_t, z_{t+1})`
  - 输出：`a_t`

训练目标：

```text
L_forward = || Δz_pred - (z_{t+1} - z_t) ||²
L_inverse = || a_pred - a_t ||²
L_total   = L_forward + β * L_inverse
```

也可以先加一个小 projection：

```text
h_t = Proj([DINO(obs_t), agent_pos_t])
```

再在 `h` 空间里学残差和 inverse dynamics。

### 3.2 最相关竞品

1. **WAM / World-Action Model**  
   链接：https://arxiv.org/abs/2603.28955  
   这篇最接近我们的“问题意识”：只做视觉预测不够，需要动作相关约束。

2. **Dream Diffusion Policy (DDP)**  
   链接：https://arxiv.org/abs/2603.21017  
   它说明 world-model regularization 可以成立，但路线更重，且依赖共享 3D visual encoder。

3. **LaDi-WM**  
   链接：https://arxiv.org/abs/2505.11528  
   它说明 latent prediction 通常比 pixel prediction 更容易学，但它是更重的 latent diffusion world model。

4. **DiWA**  
   链接：https://arxiv.org/abs/2508.03645  
   更偏 world-model-assisted adaptation，不是我们这种轻量训练时世界模型。

### 3.3 新颖性判断

新颖性判断：

- **不是空白**
- 但如果把 claim 收成：
  > 在标准 Diffusion Policy 上，先构造 action-relevant residual world model，再把它接回 DLOS 约束
  这条线仍然有相对独立的研究空间。

更准确地说，它的新颖性来自：

- `residual latent` 而不是 `absolute next latent`
- `inverse dynamics` 让 latent 变得 action-relevant
- 作为 `v3.5` 的前置 world model 改造，而不是单独做一个重型 planner

### 3.4 可行性判断

可行性：**高**

原因：

- 不需要重写官方 DP 主干
- 先改 `Stage 0` 就能看到信号
- 可以复用当前 `dlos_dp` 代码框架
- 只需要改：
  - `stage0_wm_probe.py`
  - `world_model.py`
  - 后续再决定是否接回 `train_dlos.py`

### 3.5 为什么它更有机会赢 baseline

因为它直接解决了我们当前 `Stage 0` 最明确的失败原因：

- 不再被 copy baseline 压制
- 不再要求 frozen DINO CLS 直接承担单步 absolute dynamics
- 显式鼓励 latent 对动作变化敏感

### 3.6 风险

- inverse dynamics 可能让表示过度偏动作，损害泛化
- 若 `Proj(DINO, agent_pos)` 仍不够几何化，收益可能有限

### 3.7 总评

> **最平衡的主线。**
> 它不是最“炸裂”的新故事，但最有可能在科学上站得住，同时也最容易从我们现有代码继续推进。

## 4. 方向二：Privileged-State-Aligned DLOS

### 4.1 核心想法

因为当前只做仿真，不做真机，所以可以利用 simulator state 作为训练时 teacher。

做法：

1. 训练一个视觉表征 `h_t = Enc(obs_t)`  
2. 用 privileged state 对齐 `h_t`
3. 让 world model 在这个 `state-aligned latent` 空间里做预测
4. 再把该 latent 用到 DLOS 约束里

形式上可以是：

```text
L_align = || Proj(h_t) - Proj(s_t) ||²
L_wm    = || WM(h_t, a_t) - h_{t+1} ||²
```

### 4.2 最相关竞品

这条线没有一个和我们完全重合的标准 DP 竞品，但最接近的邻域包括：

1. **SPOT**  
   链接：https://arxiv.org/abs/2411.00965  
   用 object pose trajectory 作为 object-centric中间表示，再条件 diffusion policy。

2. **MBA**  
   链接：https://arxiv.org/abs/2411.09658  
   先生成 object motion，再用 object motion guide 动作。

3. **AnchorDP3**  
   链接：https://arxiv.org/abs/2506.19269  
   使用 simulator-supervised segmentation 和 full-state style supervision 来增强 diffusion manipulation。

4. **ISS Policy**  
   链接：https://arxiv.org/abs/2512.15020  
   更偏 3D scene supervision，但也说明“纯 appearance latent 不够好”。

### 4.3 新颖性判断

新颖性：**中等偏低到中等**

因为：

- “训练时利用 simulator privileged info” 这件事本身很常见
- 但把它和 `DLOS` 结合，做成**denoising-level action-conditioned world model constraint**，仍然有自己的切口

这条线不适合宣称“非常新”，更适合宣称：

> 在仿真条件下，用 privileged state 改善 DLOS 所需的 controllable latent。

### 4.4 可行性判断

可行性：**高**

原因：

- 你当前任务全是仿真
- Push-T / Lift / Can 都更容易拿到低维状态
- 相比 object-centric 方法，工程更稳
- 相比 residual-only 方法，更容易直接得到正信号

### 4.5 为什么它最容易超过 baseline

因为它绕开了当前最难的那一步：

- 不再要求 frozen image latent 自己就足够可控
- 直接借助 simulator state 提供训练时几何目标

这会明显提高：

- world model 的可学性
- DLOS 约束的物理相关性
- 在 Push-T 上先打出增益的概率

### 4.6 风险

- 容易被 reviewer 说“仿真特权太强，现实意义有限”
- 需要非常清楚地区分：
  - 训练时可用 privileged info
  - 推理时是否仍然只用图像

### 4.7 总评

> **最容易在仿真里先赢 baseline。**
> 如果我们的目标是尽快把 `v3.5` 拉回正结果，这条线的胜率最高。

## 5. 方向三：Object-Motion DLOS

### 5.1 核心想法

不要让 world model 预测全局视觉 latent，而是预测更贴操控本质的 object-centric target：

- object motion
- object pose delta
- keypoint motion
- block/target 的相对位姿变化

然后把这个目标作为 denoising-level consistency：

```text
L_obj = || WM_obj(obj_t, x_hat0|k) - obj_{t+1} ||²
```

### 5.2 最相关竞品

1. **MBA / Motion Before Action**  
   链接：https://arxiv.org/abs/2411.09658  
   先预测 object motion，再用 motion guide 动作生成。  
   这是最强的直接邻居之一。

2. **SPOT**  
   链接：https://arxiv.org/abs/2411.00965  
   用 object pose trajectory 作为 diffusion policy 的条件。

3. **PointWorld**  
   链接：https://arxiv.org/abs/2601.03782  
   用 3D point flow 统一状态和动作，是更重型、更大规模的 object-/geometry-centric world model。

4. **Object-Centric World Model for Language-Guided Manipulation**  
   链接：https://arxiv.org/abs/2503.06170  
   说明 object-centric latent world model 在 manipulation 控制里是有效方向。

### 5.3 新颖性判断

新颖性：**中等偏高**

原因：

- object motion / object pose 作为中间表示已经有人做
- 但把它和我们现在的 `DLOS` 结合成：
  - `x̂0|k`
  - action-conditioned WM
  - denoising-level consistency
  这一具体组合仍然没那么拥挤

### 5.4 可行性判断

可行性：**中等偏低**

原因：

- 需要设计 object-centric 表示
- 可能需要额外提取：
  - pose
  - mask
  - keypoint
  - relative transform
- Push-T 虽然简单，但要把 object motion 做得稳，工程量比方向 1/2 大不少

### 5.5 为什么它可能最终最强

因为它最贴操控任务的真正因果链：

> 动作不是为了让“整张图”变化，而是为了让“目标物体运动到正确状态”。

从这个角度看，object-motion supervision 比 global latent supervision 更接近操控本体。

### 5.6 风险

- 前期工作量大
- 很容易在 representation 设计上反复试错
- 如果 object target 提得不好，会比方向 1 更慢出结果

### 5.7 总评

> **研究味最强，但不是最适合现在马上开跑的方向。**

---

## 6. 三方向与竞品的总对比

| 方向 | 核心改动 | 最近竞品 | 与竞品区别 | 新颖性判断 | 可行性 |
| --- | --- | --- | --- | --- | --- |
| `Action-Relevant Residual WM` | `Δz` + inverse dynamics | `WAM`, `DDP`, `LaDi-WM`, `DiWA` | 更轻、更插件化、更贴我们已有 DP 代码 | 中等 | 高 |
| `Privileged-State-Aligned DLOS` | 用 simulator state 对齐 latent，再做 DLOS | `SPOT`, `MBA`, `AnchorDP3`, `ISS` | 更偏训练时特权对齐，而不是直接用 object motion/pose 做 policy 条件 | 中等偏低到中等 | 高 |
| `Object-Motion DLOS` | 用 object motion / pose 做 DLOS target | `MBA`, `SPOT`, `PointWorld`, `Object-Centric WM` | 在 object-centric target 上加入 denoising-level action-conditioned WM 约束 | 中等偏高 | 中等偏低 |

## 7. 推荐顺序

### 7.1 如果只选一条主线

我建议：

**主线：`Action-Relevant Residual World Model`**

原因：

- 直接解释并修复当前 `v3.5 Stage 0` 的失败
- 不需要推翻 `dlos_dp`
- 工程代价最合理
- 科学叙事也稳

### 7.2 如果目标是“尽快比 baseline 更好”

选：

**`Privileged-State-Aligned DLOS`**

因为它最容易在仿真里先拿到正信号。

### 7.3 如果目标是“更像一篇有野心的研究”

选：

**`Object-Motion DLOS`**

但这条应该作为第二阶段，不建议现在直接拿来替代主线。

---

## 8. 建议的下一步

### 8.1 立刻可做的最小实验

先做一个新的 `Stage 0'`：

1. `h_t = Proj([DINO(obs_t), agent_pos_t])`
2. 比较四个 world model 目标：
   - `copy baseline`
   - `absolute next h`
   - `residual Δh`
   - `residual Δh + inverse dynamics`

通过标准：

- 至少有一个模型优于 copy baseline
- 或 inverse dynamics 显著提升 action recoverability

### 8.2 如果 `Stage 0'` 成立

再把最优版本接回 `DLOS`：

- 先跑 `A` vs `D`
- 不直接一口气开 `A/B/C/D/E`
- 先确认：
  - `D > A`
  - 并且该提升不是随机波动

---

## 9. 最终判断

我们现在最关键的认知更新不是“换一个更大的 world model”，而是：

> **先把 world model 所依赖的表示变成 action-relevant、geometry-relevant，再谈 denoising-level consistency。**

这也是为什么：

- `v2` 失败
- `v3.1` 失败
- `v3.5 Stage 0` 暂时也没过 gate

它们共同指向的都不是“方向错了”，而是：

> **我们一直在用一个对操控不够敏感的状态表示去承载 world-model 信号。**
