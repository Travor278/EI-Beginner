## 0. 历史失败总结

在进入 SFC-DP 之前，先明确三轮已知失败和它们指向的共同诊断：

| 版本 | 实验结论 | 根因 |
| --- | --- | --- |
| v2 手工课程 | `easy_to_hard / hard_to_easy` 双双不及 `random`（0.69 vs 0.86） | `length+variance` 是轨迹表面统计，不反映操控本质难度 |
| v3.1 预测难度重加权 | `soft_hard` 双 seed 均弱于 `uniform`（0.75/0.89 vs 0.90/0.96） | 信号接入位置太浅，偏斜采样破坏训练分布 |
| v3.5 Stage 0 | OutcomeWorldModel（DINO+action）val_mse=0.202，低于 copy baseline 0.093 | 冻结 DINO CLS 对 Push-T 合成图像单步动作变化不敏感；相邻帧 Δz ≈ 0，copy 天然占优 |

三轮失败共同指向的不是"world model 方向错误"，而是：

> **我们一直在用对操控不够敏感的表示空间去承载监督信号。**

SFC-DP 绕开这一死穴的方式是：**完全不依赖外部 world model**，直接在扩散损失内部构造频率一致性约束。

## 1. SFC-DP 核心思想

### 1.1 一句话定义

在 Diffusion Policy 训练时，对每个噪声级别 k 下的中间干净动作估计 x̂₀|k 施加
**SNR-aware 频率选择性监督**：
- 高噪声步（k≈T，ᾱ_k→0）：只要求低频（粗略运动方向）正确
- 低噪声步（k≈0，ᾱ_k→1）：要求全频段（含精细轨迹细节）正确

### 1.2 为什么这个信号之前没人利用

DDPM 的噪声 schedule 隐含了一个物理事实：

- k≈T 时，x_k≈纯噪声，模型只能可靠估计动作序列的**低频成分**（全局速度轮廓）
- k≈0 时，x_k≈x₀，**所有频率**均可恢复（含精细末端修正）

标准 DP 的 ε-loss 隐含这一性质，但从未**显式利用**。
SFC-DP 是第一个把 DCT 频率掩码与 ᾱ_k 直接对齐作为训练损失的工作。

### 1.3 与现有工作的精确区别

| 工作 | 核心操作 | 和 SFC-DP 的区别 |
| --- | --- | --- |
| FreqPolicy (2506.01583) | 将动作生成重构为频段自回归（改架构） | 我们保留标准 DDPM，只加训练损失 |
| Wavelet Policy (2504.04991) | 用小波变换替换动作表示 + 多解码器 | 我们不改动作表示，是 drop-in 训练改进 |
| DLOS-DP (v3.5) | 通过世界模型约束 x̂₀|k 的观测一致性 | 我们通过 DCT 约束 x̂₀|k 的频率一致性；不需要 WM 或 DINO |
| Min-SNR (2303.09556) | 标量时间步重加权 | 我们是频带选择性监督，不是标量权重 |
| Blurring Diffusion | 改变 forward process | 训练 loss 仍是标准像素 MSE，没有频率-SNR 对齐 |

## 2. 核心数学

### 2.1 中间动作估计

从 ε-prediction 参数化推导 x₀ 的中间估计：

```
x̂₀|k = ( x_k − √(1−ᾱ_k) · ε_θ(x_k, k, obs) ) / √ᾱ_k
```

其中 x_k = √ᾱ_k · x₀ + √(1−ᾱ_k) · ε 是加噪后的训练样本。

### 2.2 总损失

```
L_total = L_diff + λ · L_freq

L_diff = E[ || ε_θ(x_k, k, obs) − ε ||² ]          ← 标准扩散损失（不变）

L_freq = E[ || (DCT(x̂₀|k) − DCT(x₀)) · M(k) ||² ] ← 频率选择性监督
```

### 2.3 频率掩码 M(k)

```
M(k)[f] = 1   if  f / T_pred < ᾱ_k   （仅监督 SNR 足够高时可恢复的频带）
         = 0   otherwise
```

其中 f 是 DCT 系数的频率索引，T_pred 是动作块长度（Push-T 为 16）。

**掩码的直觉**：
- k=T（ᾱ_k≈0）：mask ≈ 全零，几乎不施加频率约束（模型估计太嘈杂）
- k=T/2（ᾱ_k≈0.5）：mask 覆盖前一半频率（只要求低频正确）
- k=0（ᾱ_k≈1）：mask ≈ 全一，要求全部频率正确

可选软掩码（`soft_mask=True`）：

```
M_soft(k)[f] = σ( (ᾱ_k − f/T_pred) / τ )
```

其中 τ 是温度参数（默认 0.05）。

### 2.4 梯度路径

```
L_freq → DCT(x̂₀|k) → x̂₀|k → ε_θ（主去噪网络）
                          ↑
                ∂x̂₀|k/∂ε_θ = −√(1−ᾱ_k)/√ᾱ_k
```

梯度自然穿透 x̂₀|k 回到去噪网络本身，不需要 stop-grad（消融组 E 会切断此路径）。

## 3. 消融设计（5 组）

| 组别 | 方法 | 测试目的 | 期望排名 |
| --- | --- | --- | --- |
| **A** | 标准 DP，无 L_freq | Baseline | — |
| **B** | L_freq，mask=全 1（无 SNR 对齐） | 验证 SNR-aware masking 是否是关键 | ≥A |
| **C** | L_freq + SNR mask，作用于 ε 空间而非 x̂₀|k | 验证 x₀ 预测空间是否比 ε 空间更好 | B≥C≥A 或 D>C |
| **D** | SFC-DP full（L_freq + SNR mask + x̂₀|k） | 设计上的完整方法 | 高上限候选 |
| **E** | 同 D，但 x̂₀|k 在 DCT 前 stop-grad | 验证梯度穿透 ε_θ 是否重要 | D>E |

**原始假设**：D > C > B ≥ A，D > E

**截至 2026-04-15 的阶段性实测**：

- `seed42`: `D > E > B > A`
- `seed43`: `E > A > B > D`

这说明：

- `D` 仍然是高上限组；
- `E` 目前是更稳的候选；
- `B` 说明频率监督本身有效；
- `C` 还未进入正式诊断。

### 4.2 核心损失实现（sfc_loss.py 关键片段）

```python
def sfc_loss(noise_pred, noisy_action, gt_action, timesteps, alphas_cumprod,
             group="D", soft_mask=False, soft_mask_tau=0.05):
    if group == "A":
        return torch.zeros(1, ...)        # 纯 baseline，不加 L_freq

    T_pred = gt_action.shape[1]
    abar = alphas_cumprod[timesteps].clamp(min=1e-5)          # (B,)

    # 频率掩码
    freq_idx = torch.arange(T_pred, ...).float() / T_pred     # (T_pred,)
    if soft_mask:
        mask = torch.sigmoid((abar.unsqueeze(1) - freq_idx.unsqueeze(0)) / soft_mask_tau)
    else:
        mask = (freq_idx.unsqueeze(0) < abar.unsqueeze(1)).float()  # (B, T_pred)
    mask = mask.unsqueeze(-1)                                  # (B, T_pred, 1)

    if group == "C":
        # ε-空间消融
        abar_v = abar.view(-1, 1, 1)
        eps_gt = (noisy_action - abar_v.sqrt() * gt_action) / (1 - abar_v).sqrt()
        X_pred, X_gt = _dct(noise_pred), _dct(eps_gt)
    else:
        # 组 B/D/E：x̂₀|k 空间
        x0_hat = compute_x0_hat(noisy_action, noise_pred, timesteps, alphas_cumprod)
        x0_hat = x0_hat.clamp(-3.0, 3.0)  # 防止未训练网络 DCT 系数爆炸（见第 10 节）
        if group == "E":
            x0_hat = x0_hat.detach()      # stop-grad
        X_pred, X_gt = _dct(x0_hat), _dct(gt_action)

    return F.mse_loss(X_pred * mask, X_gt * mask)
```

DCT 优先使用 `torch-dct`（`pip install torch-dct`），失败时自动回退到基于 `torch.fft` 的手写实现，无需额外配置。

### 4.3 训练脚本集成方式

`train_sfc.py` 在标准 DP 训练循环里加入：

```python
loss_diff = F.mse_loss(noise_pred, noise)
loss_freq = sfc_criterion(noise_pred, noisy_action, naction, timesteps)
loss = loss_diff + loss_freq       # loss_freq 对 group A 为 0
```

val 阶段只记录 `loss_diff`（扩散损失），避免 λ 超参影响跨组比较。

| 步骤 | 内容 | 并行/串行 | 目的 |
| --- | --- | --- | --- |

### Step 1：固定当前证据，明确主候选

这一步已经完成，结论不是“`D` 完全成立”，而是：

- `B/E` 两组已经补齐到双 seed；
- `D` 在 `seed42` 上最强，但在 `seed43` 上回落；
- `E` 是当前**最稳**的候选，因为它在两个 seed 上都超过了 `A`。

当前最重要的结果表见第 11 节。

### Step 2：`A vs E` 延长到 `200 epochs × 2 seeds`

**目标**：回答一个很关键的问题：

> `E` 现在的稳定优势，是不是因为 stop-grad 版本更适合长训练，而不是只在 100 epochs 下偶然占优？

推荐先做：

```bash
python sfc_dp/train_sfc.py --group A --seed 42 --epochs 200 ...
python sfc_dp/train_sfc.py --group E --seed 42 --epochs 200 --lambda-freq 0.01 ...
python sfc_dp/train_sfc.py --group A --seed 43 --epochs 200 ...
python sfc_dp/train_sfc.py --group E --seed 43 --epochs 200 --lambda-freq 0.01 ...
```

**通过标准**：

- `E` 在两个 seed 上都不低于对应 `A`；
- 且 `E` 的双 seed 平均分仍然高于 `A`；
- 如果 `E` 在 200 epochs 下继续拉开差距，就把 `E` 提升为当前正式主方法。

### Step 3：按 `A/E 200ep` 结果决策扩组

#### 情形 A：`E > A` 在双 seed 上继续成立

继续 `v3.6` 主线，下一步优先补 `C`：

```bash
# 先做 C × 2 seeds，确认 x̂₀|k 空间是否真的优于 ε 空间
python sfc_dp/train_sfc.py --group C --seed 42 --lambda-freq 0.01 ...
python sfc_dp/train_sfc.py --group C --seed 43 --lambda-freq 0.01 ...
```

如果 `E > C > B > A`，那么故事会很干净：

- 频率监督有效（`B > A`）
- `x̂₀|k` 空间优于 `ε` 空间（`E > C`）
- stop-grad 版本更稳（`E > D` 或 `E ≈ D` 但方差更小）

#### 情形 B：`E ≈ A`，但仍明显优于 `B/D`

说明 `v3.6` 有机制价值，但 Push-T 已经接近 ceiling。  
这时不建议继续在 Push-T 上堆更多组，应该换 task：

- `robomimic Lift`
- 或更长 horizon 的 Push-T 变体

#### 情形 C：`E` 在长训后也不稳

那就把 `v3.6` 作为“频率监督有信号但不够稳”的分支收住，回到更强 task 或更强表示主线，不再扩完整矩阵。

## 10. Stage 1 First-Pass 故障诊断与修复（seed=42，100 epochs）

### 10.1 实验结果

| epoch | A test/mean_score | D test/mean_score | D λ·L_freq | D L_diff |
| ----- | ----------------: | ----------------: | ---------: | -------: |
| 0     | 0.074             | **0.026**         | **8.762**  | 0.225    |
| 10    | 0.443             | **0.020**         | 0.549      | 0.060    |
| 20    | 0.682             | **0.020**         | 0.219      | 0.053    |
| 30    | 0.579             | **0.021**         | 0.134      | 0.048    |
| 40    | 0.726             | 0.379             | 0.090      | 0.038    |
| 60    | **0.839**         | 0.596             | 0.030      | 0.030    |
| 80    | **0.855**         | 0.598             | 0.007      | 0.025    |
| 90    | 0.808             | **0.705**         | 0.003      | 0.023    |

best_metric：A = 0.855，D = 0.705（D 差 A 约 15 points）

### 10.2 根因：L_freq 初始值失控，早期训练窗口完全丢失

epoch 0 时：

```
L_diff  ≈ 0.225   （正常扩散损失）
L_freq  ≈ 87.6    （未训练网络 ε_θ 随机，x̂₀|k 经 1/√ᾱ_k 放大后 DCT 系数极大）
λ·L_freq ≈ 8.76  （λ=0.1，仍是 L_diff 的 39 倍）
```

结果：D 在 epoch 0-30 完全停滞（test_score≈0.02），而 A 同期已到 0.44-0.68，
早期最关键的学习窗口被完全摧毁。

一个重要反直觉发现：**D 的扩散损失最终收敛比 A 更好**
（epoch 99 val_loss：D=0.0315 < A=0.0524），说明频率约束方向正确，
问题完全是工程上的 loss scale 而非理论缺陷。

### 10.3 已实施的三个修复（代码已同步更新）

#### 修复 1：λ 从 0.1 → 0.001（100× 降低）

- 文件：`sfc_dp/config.py`，`lambda_freq: float = 0.001`
- CLI：`--lambda-freq 0.001`（默认值已改）
- 理由：epoch 0 时 λ=0.001 给出 λ·L_freq ≈ 0.088，与 L_diff=0.225 量级相当

#### 修复 2：x̂₀|k 在 DCT 前 clamp 到 [-3, 3]

- 文件：`sfc_dp/sfc_loss.py`，`x0_hat = x0_hat.clamp(-3.0, 3.0)`
- 理由：归一化动作空间约为 [-1,1]，±3 是合理上界；
  防止极端 timestep（ᾱ_k≈0）时 1/√ᾱ_k 放大效应

#### 修复 3：λ 线性 warmup（0 → lambda_freq，默认 20 epochs）

- 文件：`sfc_dp/config.py`，新增 `lambda_warmup_epochs: int = 20`
- 训练循环：每个 epoch 开始前 `policy.sfc_loss_fn.lambda_freq = λ · min(1, epoch/warmup)`
- 理由：即使 λ=0.001，epoch 0 的 L_freq 仍会产生干扰；
  warmup 确保最初几个 epoch 完全由 L_diff 主导

三项修复叠加后，epoch 0 的 λ·L_freq 从 **8.76** 降至 **0**（warmup 起点），
到 epoch 20 才逐渐达到 0.001 × 当时已收敛的 L_freq（≈ 0.002~0.005），
不再干扰早期训练。

## 12. 当前诊断总结与下一步 gate

### 12.1 四个当前最重要的发现

**发现 1：频率监督本身成立**

`B > A` 在双 seed 上都成立，说明“DCT + 频率约束”不是噪声，而是有效监督信号。

**发现 2：stop-grad 版本更稳**

`E > A` 在双 seed 上都成立，且平均最高、跨 seed 波动最小。  
这比只看单个 best score 更重要，因为它说明当前最可靠的版本不是 `D`，而是 `E`。

**发现 3：梯度穿透带来高上限，但也带来方差**

`D_seed42_lam0p01 = 0.9519` 是目前全表最高分，说明 `D` 的机制不是假的。  
但 `D_seed43_lam0p01 = 0.8961 < A_seed43`，说明它现在还不够稳。

**发现 4：soft mask 目前没有带来收益**

`D_seed42_softmask = 0.8679 < D_seed42(hard)=0.8826`，  
说明当前阶段没有必要继续在 `soft_mask` 上花更多预算。

### 12.2 下一步 gate

下一步不再建议直接铺 `B/C/D/E × 2 seeds` 的完整大矩阵。  
当前最高性价比的验证是：

1. `A vs E` 延长到 `200 epochs × 2 seeds`
2. 如果 `E` 继续稳定优于 `A`，再补 `C × 2 seeds`
3. 如果 `E` 在长训下也不稳，再考虑换 task（如 `robomimic Lift`）

### 12.3 决策树（按当前结果更新）

