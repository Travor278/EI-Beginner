# Diffusion Policy 研究方向 v3.5
# Denoising-Level Outcome Supervision for Diffusion Policy（DLOS-DP）

> 版本历史：v2 课程排序失败 → v3 Latent Dynamics Regularization（辅助 loss 于 GT 动作）
> → v3.1 预测难度重加权（与 QoQ 竞品冲突）→ **v3.5 去噪时 WM 一致性（当前主线）**

---

## 0. 一句话方向

> 在 Diffusion Policy 训练过程中，**对每个 noise level k 下的中间干净动作估计 x̂₀|k
> 施加 action-conditioned 世界模型一致性约束**，使梯度直接穿透去噪网络，在每个噪声
> 层强迫模型产生物理上可行的动作估计。

---

## 1. 核心问题

标准 Diffusion Policy（DDPM）只有一个训练信号：

```
L_diff = E_{k, ε} [ || ε_θ(x_k, k, obs) − ε ||² ]
```

这个 loss 只告诉模型"怎么去噪"，**不告诉模型"去噪后的动作是否物理可行"**。

结果是：模型在 action distribution 的边界外泛化能力差，在少样本条件下容易过拟合噪声。

### 现有修复思路的问题

| 方法 | 修复方式 | 遗留问题 |
|---|---|---|
| ISS Policy (2512.15020) | 最终动作 x₀ → 预测未来场景 | 只约束最终输出，不约束去噪中间步骤 |
| ForeDiffusion (2601.12925) | 预测未来 view → 条件进入去噪 | 因果方向反向（future→action），不约束动作对未来的影响 |
| PAD (NeurIPS 2024) | 联合去噪 action + future image | 架构重设计，需要 video 数据共训练 |
| CLaD (2603.29409) | EMA latent foresight | 0.66B 参数，独立于去噪过程 |
| v3（原始） | GT action → 预测下帧 embedding | 梯度不穿透 ε_θ（用 GT 动作，非模型预测）|

**缺口**：没有人在每个 noise level k 对 DP 自身的中间动作估计施加 action-conditioned 的
物理一致性约束，也没有人让这个约束的梯度穿透去噪网络本身。

---

## 2. 方法：DLOS-DP

### 2.1 关键公式

在 DDPM x₀-预测参数化下（或从 ε-预测推导），noise level k 的中间干净动作估计为：

```
x̂₀|k = ( x_k − √(1−ᾱ_k) · ε_θ(x_k, k, obs) ) / √ᾱ_k
```

其中 x_k = √ᾱ_k · x₀_gt + √(1−ᾱ_k) · ε 是加噪后的训练样本。

DLOS-DP 的总 loss：

```
L = L_diff + λ(k) · L_wm

L_diff = || ε_θ(x_k, k, obs) − ε ||²

L_wm   = || WM( DINOv2(obs_t),  x̂₀|k[0:a_dim] )  −  stopgrad(DINOv2(obs_{t+1})) ||²

λ(k)   = ᾱ_k · λ_global          （SNR 加权，稳定高噪声层梯度）
```

其中：
- `WM`：轻量 MLP，约 200K 参数
- `DINOv2`：冻结的 ViT-S/14，输出 384 维 embedding
- `x̂₀|k[0:a_dim]`：中间估计的第一个 action（2 维，用于单步 forward dynamics）
- `stopgrad(DINOv2(obs_{t+1}))`：目标不更新 DINO 权重

### 2.2 梯度路径（核心创新）

```
L_wm → WM → x̂₀|k → ε_θ（UNet 主网络）
                ↑
        ∂x̂₀|k/∂ε_θ = −√(1−ᾱ_k)/√ᾱ_k
        经 λ(k)=ᾱ_k 加权后等效系数：−√ᾱ_k·√(1−ᾱ_k) ≤ 0.5（有界）
```

**v3（原始）中的梯度路径**：L_dyn → WM → encoder（GT action 不经过 ε_θ）

**DLOS 的梯度路径**：L_wm → WM → x̂₀|k → **ε_θ 主网络**

这是两者的本质区别：DLOS 直接约束去噪网络本身，而不是旁路监督。

### 2.3 World Model 架构

```python
class OutcomeWorldModel(nn.Module):
    """轻量 action-conditioned forward model，预测单步 DINO 特征变化"""
    def __init__(self, obs_dim: int = 384, action_dim: int = 2, hidden: int = 256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim + action_dim, hidden),
            nn.LayerNorm(hidden),
            nn.SiLU(),
            nn.Linear(hidden, hidden),
            nn.LayerNorm(hidden),
            nn.SiLU(),
            nn.Linear(hidden, obs_dim),
        )

    def forward(self, z_obs: torch.Tensor, action: torch.Tensor) -> torch.Tensor:
        """
        Args:
            z_obs:   DINOv2 embedding of obs_t,   shape (B, 384)
            action:  first action of chunk x̂₀|k,  shape (B, 2)
        Returns:
            predicted z_{t+1},                    shape (B, 384)
        """
        return self.net(torch.cat([z_obs, action], dim=-1))
```

参数量：(384+2)×256 + 256×256 + 256×384 ≈ **247K 参数**（可忽略）

### 2.4 有效 k 范围

| k 范围 | x̂₀|k 质量 | 梯度有效性 | 策略 |
|---|---|---|---|
| k > 0.7T | 噪声极大，近随机 | λ(k)≈0，基本无贡献 | 自然过滤 |
| k ∈ [0.4T, 0.7T] | 中等粗粒度估计 | 提供粗方向约束 | 主要贡献区 |
| k ∈ [0, 0.4T] | 较精细估计 | 提供精细约束 | 主要贡献区 |

**SNR 加权 λ(k)=ᾱ_k 自然实现了这个过滤**，无需手动设置阈值。

## 3. 与竞品的精确区分

| 工作 | action 来源 | WM 梯度是否穿透 ε_θ | 噪声层是否感知 | 规模 |
|---|---|---|---|---|
| **ISS (2512.15020)** | 最终 x₀（3D 点云） | ✗（x₀ 是叶节点） | ✗ | 中 |
| **ForeDiffusion (2601.12925)** | 无（future→action 方向） | ✗（独立预测器） | ✗ | 中 |
| **PAD (NeurIPS 2024)** | 联合去噪（无分离） | N/A（同一网络） | ✗ | 重 |
| **v3（原始）** | GT action（训练数据） | ✗（GT 不流梯度） | ✗ | 轻 |
| **CLaD (2603.29409)** | EMA 特征（无 action） | ✗ | ✗ | 0.66B |
| **DLOS-DP（我们）** | **x̂₀\|k（模型自身估计）** | **✓** | **✓（λ(k)=ᾱ_k）** | **轻** |

**DLOS 的唯一性**：唯一一个让 action-conditioned WM 的梯度在每个 noise level
穿透回去噪网络本身的轻量方法。

### 为什么比 v3 强

v3 实质上等价于"ISS-style auxiliary task on ground truth data"，梯度只流向 encoder。
DLOS 的梯度路径更深：`WM → x̂₀|k → ε_θ`，直接塑造去噪过程如何生成动作。

## 4. 贡献声明

### 主要贡献（适合投 CoRL / IROS / RA-L 级别）

1. **提出 Denoising-Level Outcome Supervision（DLOS）**：
   首次在 Diffusion Policy 训练中，将 action-conditioned 世界模型的一致性约束
   施加于每个 noise level k 的中间干净估计 x̂₀|k，让梯度直接穿透去噪网络。

2. **SNR-aware 加权（λ(k) = ᾱ_k）**：
   给出理论上有界且峰值在 k≈T/2 的梯度系数，无需手动调整有效噪声层范围。

3. **系统消融**：
   区分四种监督方式（无 WM / GT-action WM / final-action WM / intermediate-k WM），
   从实验上回答"在哪个 action 来源上施加 WM 约束效果最好"。

4. **负结果的完整故事**：
   手工难度课程（v2）→ 轻量辅助 dynamics loss（v3/v3.1）→ 去噪时 WM 约束（v3.5），
   形成从"数据顺序"到"数据信号"到"模型内部物理约束"的演化链条。

### 贡献范围边界（不应夸大）

- 不声称"首次做 world model × DP"（PAD、ISS、ForeDiffusion 已存在）
- 不声称"最优的 world model 方法"（重型方法如 PAD 在大数据下可能更强）
- 声称"在现有 DP 架构上加最小改动实现 WM 一致性的首个去噪层次感知方法"

## 5. 验证路径

### Stage 0：WM 可学性验证（1 天，无风险）

**目标**：在 Push-T 数据集上独立训练 OutcomeWorldModel，验证其能学到有效动力学。

```python
# 独立训练脚本，不与 DP 联合
optimizer = AdamW(wm.parameters(), lr=1e-4)
for epoch in range(50):
    for obs_t, action_t, obs_next in dataloader:
        z_t    = dino(obs_t).detach()
        z_next = dino(obs_next).detach()
        z_pred = wm(z_t, action_t[:, 0, :])   # 只用 chunk 第一步 action
        loss   = F.mse_loss(z_pred, z_next)
        loss.backward(); optimizer.step()
```

**通过标准**：验证集 L2 prediction error 稳定收敛（约 30-50 epoch）。
与 random baseline（直接预测 z_t 作为 z_{t+1}）相比，L2 误差降低 ≥ 20%。

**如果失败**：WM 学不到 Push-T 动力学 → 方向在这个 task 上失效，立刻换 task 或换 obs 表示。

---

### Stage 1：关键消融对比（2-3 天，决定方向生死）

这是整个 v3.5 方向的生死实验。

**实验矩阵（Push-T image，full data，seed=42 和 seed=43）**：

| 组别 | 方法 | 说明 |
|---|---|---|
| A | DP baseline | 标准训练，无任何 WM |
| B | v3-style（GT-action WM） | WM(z_t, a_gt) → ẑ_{t+1}，梯度不穿透 ε_θ |
| C | ISS-2D（final-action WM） | WM(z_t, x₀_final[0:2]) → ẑ_{t+1}，最终输出 |
| D | **DLOS-DP**（x̂₀\|k WM） | WM(z_t, x̂₀\|k[0:2]) → ẑ_{t+1}，SNR 加权 |
| E | DLOS-stopgrad | D 但 stopgrad(x̂₀\|k)（验证梯度流的贡献）|

共 5 × 2 seeds = 10 个 run，每个 run 约 50 epoch，Push-T 上约 1-2 小时。

**判断逻辑**：

```
D > C > B ≥ A  →  DLOS 完整成立，方向确认
D > C ≈ B ≥ A  →  中间层 WM 有效，但 GT vs final 无差别
D ≈ C > B ≥ A  →  WM 有用，但中间层无额外贡献（退化为 ISS-2D）
D ≈ C ≈ B ≈ A  →  WM 在 Push-T 上整体无效，换 task
D > E（且 D > C）→  梯度穿透是关键机制（论文核心 claim）
```

**通过标准**：D 相比 A 提升 ≥ 3 points（Push-T mean score），或 D 显著优于 C。

---

### Stage 2：低数据量验证（2-3 天，强化贡献）

**目标**：验证 DLOS 在少样本场景下的优势是否更明显（WM 正则化的主要价值来自数据稀缺）。

| 数据量 | A（baseline） | D（DLOS） | 预期 gap |
|---|---|---|---|
| full（100%） | ~0.862 | ? | 小 |
| 50 demos | 预期下降 | ? | 中 |
| 20 demos | 预期大幅下降 | ? | **期望最大** |

如果 gap 在 20 demos 时最大，说明 DLOS 的核心价值在于**低数据下的物理正则化**，这是一个干净的故事。

---

### Stage 3：第二 benchmark 泛化（3-5 天，支撑论文）

仅在 Stage 1 有正向信号后执行。

推荐任务：`robomimic Lift`（image-based，较简单，适合快速验证泛化）

| 任务 | 方法 | 数据量 |
|---|---|---|
| robomimic Lift | A, B, C, D | full / 50 demos |

**通过标准**：D 在 Lift 上也优于 A，且趋势与 Push-T 一致。

### Stage 4（可选）：x̂₀|k 多步预测扩展

如果 Stage 1-3 结果优异，考虑更强版本：

## 6. 实现指南

### 6.1 训练循环改动（最小化）

```python
# 在 train_diffusion_unet_hybrid_workspace.py 中
# 修改 compute_loss 方法

def compute_loss(self, batch):
    obs         = batch['obs']           # (B, T_obs, C, H, W)
    action      = batch['action']        # (B, T_pred, a_dim)
    obs_next    = batch['obs_next']      # (B, C, H, W) — 需添加到 dataset

    # ---- 标准 diffusion loss ----
    B = action.shape[0]
    k = torch.randint(0, self.noise_scheduler.config.num_train_timesteps,
                      (B,), device=action.device)
    eps   = torch.randn_like(action)
    alpha_bar = self.noise_scheduler.alphas_cumprod.to(action.device)[k]  # (B,)
    x_k   = (alpha_bar.sqrt()[:,None,None] * action
             + (1 - alpha_bar).sqrt()[:,None,None] * eps)
    eps_pred = self.model(x_k, k, obs)
    loss_diff = F.mse_loss(eps_pred, eps)

    # ---- x̂₀|k 计算 ----
    x0_hat = ((x_k - (1 - alpha_bar).sqrt()[:,None,None] * eps_pred)
              / alpha_bar.sqrt()[:,None,None])   # (B, T_pred, a_dim)
    a_first = x0_hat[:, 0, :]                   # (B, a_dim)，只取 chunk 第一步

    # ---- WM 一致性 loss ----
    with torch.no_grad():
        z_t    = self.dino(obs[:, -1])           # 最近一帧 obs 的 DINO embedding
        z_next = self.dino(obs_next)             # 下一帧 DINO embedding（目标）

    z_pred   = self.wm(z_t, a_first)            # WM 前向（梯度流过 a_first → x0_hat → eps_pred）
    loss_wm  = F.mse_loss(z_pred, z_next)

    # ---- SNR 加权 ----
    lambda_k = alpha_bar.mean()                  # scalar，约为 ᾱ 的 batch 平均
    loss = loss_diff + lambda_k * self.lambda_wm * loss_wm
    return loss
```

### 6.2 Dataset 改动

需要在 `pusht_image_dataset.py` 中添加 `obs_next` 字段：

```python
# 在 __getitem__ 中增加：

```

### 6.3 超参数

| 超参数 | 推荐初始值 | 说明 |
|---|---|---|
| `lambda_wm` | 0.1 | WM loss 全局权重，需做敏感性实验 |
| WM hidden dim | 256 | 约 247K 参数 |
| WM lr | 1e-4 | 独立 optimizer 或与主网络相同 |
| DINO model | `dinov2_vits14` | 384 维，约 22M 参数，冻结 |

**超参数敏感性消融**（只做 Push-T full data）：
lambda_wm ∈ {0.01, 0.05, 0.1, 0.5, 1.0}

## 8. 论文故事线（若实验通过）

```
Background:
  - DP 训练只有 denoising loss，不包含物理可行性约束
  - 现有 WM×DP 方法要么只约束最终动作（ISS），要么需要重型架构（PAD）

Method:
  - 在每个 noise level k，计算中间干净估计 x̂₀|k
  - 用轻量 WM 预测 x̂₀|k 的物理结果（下帧 DINO embedding）
  - WM 梯度穿透回去噪网络（区别于 ISS 的 k=0-only 方式）
  - SNR-aware 加权自动平衡不同噪声层的贡献

Experiments:
  - Push-T image：消融 4 种监督来源，DLOS > ISS-2D > GT-WM > baseline
  - Low-data setting：gap 在 20 demos 时最大（WM 正则化在少数据下最有价值）
  - robomimic Lift：泛化验证，趋势一致

Conclusion:
  - WM 约束应作用于去噪过程的中间层，而非仅在最终输出
  - 200K MLP 的最小代价实现 noise-level-aware 物理约束
```
