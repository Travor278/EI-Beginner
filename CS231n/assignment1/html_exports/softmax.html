Inline Question 2

Although gradcheck is reliable softmax loss, it is possible that for SVM loss, once in a while, a dimension in the gradcheck will not match exactly. What could such a discrepancy be caused by? Is it a reason for concern? What is a simple example in one dimension where a svm loss gradient check could fail? How would change the margin affect of the frequency of this happening?

Note that SVM loss for a sample $(x_i, y_i)$ is defined as: $$L_i = \sum_{j\ne y_i}\max(0, s_j - s_{y_i} + \Delta)$$ where $j$ iterates over all classes except the correct class $y_i$ and $s_j$ denotes the classifier score for $j^{th}$ class. $\Delta$ is a scalar margin. For more information, refer to 'Multiclass Support Vector Machine loss' on this page.

Hint: the SVM loss function is not strictly speaking differentiable.

$\color{blue}{\textit Your Answer:}$ The discrepancy can occur because the SVM hinge loss uses a $\max(0, \cdot)$ term, so it is not differentiable at the hinge boundary. If numerical gradient checking perturbs a parameter across such a kink, the finite-difference estimate may not exactly match the analytic gradient or subgradient chosen by the implementation. This is usually not a serious concern if it happens only occasionally and on a few dimensions. A simple one-dimensional example is $f(x)=\max(0, x)$ at $x=0$, where the left derivative is 0 and the right derivative is 1. In the multiclass SVM, the analogous boundary is when $s_j - s_{y_i} + \Delta = 0$. A larger margin $\Delta$ makes it more likely that some terms lie near this boundary, so these occasional mismatches can happen more often.

Inline question 3

Describe what your visualized Softmax classifier weights look like, and offer a brief explanation for why they look the way they do.

$\color{blue}{\textit Your Answer:}$ The visualized weights look like coarse class templates rather than natural images. Some classes show broad color and shape tendencies, for example sky or water-like regions for plane and ship, or ground-colored regions for deer and horse, but the patterns are blurry and not sharply localized. This happens because the classifier is linear: each class is represented by a single weight template over all pixels, and classification is based on the dot product between the image and that template. As a result, the model can capture only global, low-level statistics such as rough color distributions and weak spatial structure, not the richer part-based or hierarchical features that a deeper model could learn.

Inline Question 4 - True or False

Suppose the overall training loss is defined as the sum of the per-datapoint loss over all training examples. It is possible to add a new datapoint to a training set that would change the softmax loss, but leave the SVM loss unchanged.

$\color{blue}{\textit Your Answer:}$ True

$\color{blue}{\textit Your Explanation:}$ A new datapoint always contributes some softmax loss unless the model assigns probability 1 to the correct class, so in general it will change the total softmax objective. In contrast, a datapoint can contribute zero SVM loss if the correct class score already exceeds every incorrect class score by at least the margin. In that case, adding this datapoint leaves the total SVM loss unchanged while still changing the softmax loss.
