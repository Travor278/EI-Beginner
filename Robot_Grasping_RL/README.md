# 自定义机械臂抓取任务规划

这个文件夹对应任务二的最后一阶段：在 PyBullet 或 MuJoCo 中训练你自己的机械臂抓取策略，并开始理解 Sim2Real。

## 推荐推进顺序

1. `Reach-only`
   - 只要求末端到达物体上方
2. `Pre-grasp`
   - 末端到达合适抓取位姿
3. `Grasp + Lift`
   - 合拢夹爪并把物体抬离桌面
4. `Pick and Place`
   - 抓起后移动到目标区域并放下
5. `Sim2Real`
   - 加入噪声、随机化、延迟、扰动，观察策略鲁棒性

## 建议先想清楚的设计

- 观测空间：关节角、关节速度、末端位姿、物体位姿、目标位姿
- 动作空间：关节增量控制，或末端笛卡尔位移控制
- 奖励函数：到达奖励、接触奖励、夹持奖励、抬升奖励、目标完成奖励
- 终止条件：成功、掉落、超时、越界

## Sim2Real 基础检查项

- 观测噪声
- 动作延迟
- 摩擦系数随机化
- 物体质量和尺寸随机化
- 摄像头或末端位姿扰动

## 和当前仓库的连接

- `EI_Mujoco/hello_mujoco.py` 可以作为 MuJoCo 侧的最小起点
- `Robotics_NTU/` 里的正逆运动学内容可以帮助你理解动作设计和末端控制

## 本阶段完成标准

- 至少定义出一个清晰的抓取任务 MDP
- 跑通一个最小可训练环境
- 做一次基础的 domain randomization
- 写一段简短总结说明训练策略在 Sim2Real 上最脆弱的环节
